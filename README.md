# DOAX2 Recompilation Project

An experimental native recompilation project for the Xbox 360 release of
*Dead or Alive Xtreme 2*.

## Status

Pre-bootstrap research and baseline capture. No playable build exists yet.

See [ROADMAP.md](docs/ROADMAP.md) for the staged plan and acceptance gates.
Current verified bootstrap data is in
[PHASE_1_FINDINGS.md](docs/PHASE_1_FINDINGS.md).

## Repository policy

This repository must contain only original project code, configuration,
documentation, and metadata that can be shared legally. It must not contain
the game ISO, extracted game files, generated translations that embed original
game code, title updates, DLC, saves, SDK material, or other copyrighted game
content.

Read [LEGAL.md](LEGAL.md) before contributing or publishing any artifact, and
run `scripts/check_repository_hygiene.ps1` before every push.

Anyone working with the project must provide files dumped from a copy of the
game they legally own. The project is not affiliated with or endorsed by Team
Ninja, Tecmo, Koei Tecmo, or Microsoft.
