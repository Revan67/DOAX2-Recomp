# Contributing

Contributions must be original work or material the contributor has the right to
submit under a compatible license. Read [LEGAL.md](LEGAL.md) before opening an
issue or pull request.

Do not upload game files, generated translations, reverse-engineering databases,
screenshots, captures, dumps, logs, saves, proprietary SDK material, or links to
unauthorized copies. Report identifiers as factual metadata only when needed.

Before committing, run:

```powershell
pwsh -File scripts/check_repository_hygiene.ps1
```

If a contribution depends on local game-derived information, describe observable
inputs and outputs in original words and keep the underlying artifacts local.
